## Download and install

Choose the installer for your computer. You do not need a terminal, Node.js, or Rust.

| Computer                                    | Download                                                                                                                            |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Mac with Apple Silicon, macOS 13 or newer   | [Download DMG](https://github.com/rickie-austin-114/llm_proxy/releases/download/v0.1.0/LLM-Proxy-0.1.0-macOS-Apple-Silicon.dmg)     |
| Mac with Intel processor, macOS 13 or newer | [Download DMG](https://github.com/rickie-austin-114/llm_proxy/releases/download/v0.1.0/LLM-Proxy-0.1.0-macOS-Intel.dmg)             |
| Windows 11 x64                              | [Download setup EXE](https://github.com/rickie-austin-114/llm_proxy/releases/download/v0.1.0/LLM-Proxy-0.1.0-Windows-x64-Setup.exe) |

On Mac, open the DMG and drag **llm_proxy** into **Applications**. On Windows, run the setup EXE; installation may download Microsoft WebView2 if it is missing.

[Download the Word installation guide with PowerPoint screenshots](https://github.com/rickie-austin-114/llm_proxy/releases/download/v0.1.0/LLM_Proxy_PowerPoint_Installation_Guide.doc).

## Configure the app

1. Open **llm_proxy**, enter your provider API key, and save settings.
2. Keep the default Claude upstream endpoint `https://api.servicesessentials.ibm.com`, or the OpenAI endpoint `https://api.servicesessentials.ibm.com/v1`, unless your service owner supplies another endpoint.
3. For Claude in PowerPoint, complete **Office gateway HTTPS** setup and certificate trust in the app, then start the proxy and fully restart PowerPoint.
4. In the Claude add-in, choose **Cloud provider or gateway**, then **LLM Gateway**. Enter `https://localhost:8788/claude` and the same Claude API key saved in llm_proxy.

**Start at login** is enabled by default on new installations. Closing settings leaves the proxy running in the menu bar or system tray; **Quit** stops it.

## Preview status

This first release is a **preview**, with development installers. Mac applications have an ad-hoc signature without Apple Developer ID signing or notarization. The Windows installer has no publisher signature. Operating-system or organization policies can block these packages; signed production installers are still pending.

The application installer signature and the local HTTPS certificate are separate. Each computer needs its own local certificate setup through the app.

Cross-platform automated checks and packaging do not establish clean-machine installation, native certificate trust, a live Office/provider connection, or compliance with the background RAM target. Those acceptance checks remain pending; see [VALIDATION.md](https://github.com/rickie-austin-114/llm_proxy/blob/v0.1.0/VALIDATION.md).

`SHA256SUMS.txt` contains checksums for the three installers and the Word guide. Use the named installer assets above; GitHub's **Source code** ZIP and TAR downloads are for developers.
