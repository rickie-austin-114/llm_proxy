# ICA proxy v0.2.4 Preview

This preview fixes macOS worker startup when an enabled background service still points to an older app after an update, causing “The proxy worker did not start.” Saved provider keys, settings, HTTPS identity, and run preferences are preserved.

## Download and install

Choose the installer for your computer. No terminal, Node.js, or Rust is required.

| Intel Mac, macOS 13 or newer         | [Download DMG](https://github.com/rickie-austin-114/llm_proxy/releases/download/v0.2.4/ICA-Proxy-0.2.4-macOS-Intel.dmg)             |

On Mac, open the DMG and drag **ICA proxy** into **Applications**. On Windows, run the setup EXE; installation may download Microsoft WebView2 if it is missing. GitHub's source archives are for developers.

## Changes in this release

- After failed managed startup on macOS, ICA proxy makes one automatic attempt per settings session to refresh an existing enabled background registration, then verifies the worker's executable identity and run mode before sending settings or credentials.
- **Check background startup** can refresh an enabled registration even when its saved worker fingerprint matches the installed app. Native registration and signing errors remain visible instead of being hidden by an older enabled status.
- Worker identity probes and the post-launch handshake have bounded timeouts. If recovery still fails, the app provides specific guidance for approval or reinstalling the complete app while retaining data.
- Interrupted setup can reconnect to an already enrolled worker without completing the wizard or starting proxy listeners. Recovery preserves foreground mode, OS-disabled startup, and reset preferences.
- Retains **Start without background startup**, the blue macOS Keychain guidance panel, guided setup, and macOS installer-signature verification from earlier previews.

## Upgrade and configure

Quit ICA proxy settings, replace the installed app using the appropriate installer, and reopen the installed copy. On Mac, open the copy in **Applications**. Keep your saved provider keys, settings, and HTTPS identity; do not use **Reset data / prepare to uninstall** for this update or for the worker-startup error. macOS may request renewed **Always Allow** approval for the worker after its executable changes.

If macOS requests background approval, enable ICA proxy in **System Settings → General → Login Items & Extensions**, return to the app, and select **Check background startup**. If setup was incomplete, finish the wizard to start the proxy. Foreground mode continues to stop when the app closes or quits.

See the [installation instructions](https://github.com/rickie-austin-114/llm_proxy/blob/v0.2.4/README.md#install-and-configure) for setup, run modes, and approval recovery. The older Word guide shows the previous setup and tray behavior.

## Preview limitations

Mac apps use ad-hoc signing without Apple Developer ID signing or notarization. The Windows installer has no publisher signature. Operating-system or organization policies may block these development packages; signed production installers are pending.

The stale macOS service recovery was verified against the affected installed app on one Apple Silicon Mac, preserving settings and public certificate metadata. Automated tests and package verification do not establish all clean-account install/upgrade/uninstall cases, native credential and certificate prompts, foreground close/quit/crash behavior, sign-in/reboot behavior, or a live Office/provider connection. Combined background RAM below 200 MB, ideally below 100 MB, remains an unmeasured release gate. See the [validation notes](https://github.com/rickie-austin-114/llm_proxy/blob/v0.2.4/VALIDATION.md) for completed checks and pending acceptance work.
