# ICA proxy v0.2.1 Preview

ICA proxy is open-source software under the [MIT License](https://github.com/rickie-austin-114/llm_proxy/blob/v0.2.1/LICENSE). This release renames llm_proxy to **ICA proxy** and includes the license in the app package.

## Download and install

Choose the installer for your computer. No terminal, Node.js, or Rust is required.

| Computer                             | Download                                                                                                                            |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| Apple Silicon Mac, macOS 13 or newer | [Download DMG](https://github.com/rickie-austin-114/llm_proxy/releases/download/v0.2.1/ICA-Proxy-0.2.1-macOS-Apple-Silicon.dmg)     |
| Intel Mac, macOS 13 or newer         | [Download DMG](https://github.com/rickie-austin-114/llm_proxy/releases/download/v0.2.1/ICA-Proxy-0.2.1-macOS-Intel.dmg)             |

On Mac, open the DMG and drag **ICA proxy** into **Applications**. On Windows, run the setup EXE; installation may download Microsoft WebView2 if it is missing. Use the installer assets above; GitHub's source archives are for developers.

## Changes in this release

- App branding, window titles, native menus, installer metadata, and setup messages now use **ICA proxy**.
- The README identifies the app as open source, links the MIT license, and explains the rename upgrade. The MIT license is bundled with the app.
- Newly generated HTTPS certificates use the ICA proxy name. Existing saved certificate identities are retained.
- The independent background worker, automatic sign-in startup, combined HTTPS setup/trust button, and Keychain Always Allow guidance from v0.2.0 are included.

## Upgrade from llm_proxy

Quit the old app before installing ICA proxy. On Mac, install ICA proxy into Applications and remove the old llm_proxy app after confirming the new app works. On Windows, uninstall llm_proxy through Installed apps before installing ICA proxy, because the new name uses a different installation directory.

To retain saved provider keys, settings, and the HTTPS identity, skip **Reset data / prepare to uninstall** during this rename upgrade. Application and credential identifiers remain stable. macOS may request renewed **Always Allow** approval after an update; approve applicable provider and HTTPS-key prompts for **llm-proxy-worker**, whose internal executable name is retained.

Closing or quitting settings leaves the proxy running. Reopen **ICA proxy** from Applications or the Start menu to manage it. After sign-in, only the background worker starts; macOS may require background-item approval in System Settings. Existing OS-disabled startup is respected.

## Configure Claude in PowerPoint

1. Open **ICA proxy**, enter your Claude API key, and save settings. Keep the upstream endpoint `https://api.servicesessentials.ibm.com` unless your service owner supplies another endpoint. The OpenAI default remains `https://api.servicesessentials.ibm.com/v1`.
2. With the proxy stopped, open **Office gateway HTTPS** and select **Set up HTTPS and trust certificate**. Approve any OS prompt, then start the proxy and fully restart PowerPoint.
3. In the Claude add-in, choose **Cloud provider or gateway**, then **LLM Gateway**. Enter `https://localhost:8788/claude` and the same Claude API key saved in ICA proxy. There is no separate local token.

See the [current installation instructions](https://github.com/rickie-austin-114/llm_proxy/blob/v0.2.1/README.md#install-and-configure). The older Word guide uses the previous name, two-button HTTPS flow, and tray behavior.

## Preview limitations

Mac apps have an ad-hoc signature without Apple Developer ID signing or notarization. The Windows installer has no publisher signature. Operating-system or organization policies may block these development packages; signed production installers are pending.

Each computer needs its own local HTTPS setup. Automated checks do not establish clean-account upgrades, reboot/sign-in behavior, native approval flows, or a live Office/provider connection. The required combined background RAM below 200 MB, ideally below 100 MB, remains unmeasured. See [validation notes](https://github.com/rickie-austin-114/llm_proxy/blob/v0.2.1/VALIDATION.md) for completed checks and pending acceptance work.

`SHA256SUMS.txt` contains checksums for the three installers and the license.
