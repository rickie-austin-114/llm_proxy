# ICA proxy v0.2.3 Preview

This preview adds an option to run the proxy only while ICA proxy is open, and fixes the macOS Keychain guidance panel's background and text contrast in dark mode.

## Download and install

Choose the installer for your computer. No terminal, Node.js, or Rust is required.

| Computer                             | Download                                                                                                                            |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| Apple Silicon Mac, macOS 13 or newer | [Download DMG](https://github.com/rickie-austin-114/llm_proxy/releases/download/v0.2.3/ICA-Proxy-0.2.3-macOS-Apple-Silicon.dmg)     |
| Intel Mac, macOS 13 or newer         | [Download DMG](https://github.com/rickie-austin-114/llm_proxy/releases/download/v0.2.3/ICA-Proxy-0.2.3-macOS-Intel.dmg)             |
| Windows 11 x64                       | [Download setup EXE](https://github.com/rickie-austin-114/llm_proxy/releases/download/v0.2.3/ICA-Proxy-0.2.3-Windows-x64-Setup.exe) |

On Mac, open the DMG and drag **ICA proxy** into **Applications**. On Windows, run the setup EXE; installation may download Microsoft WebView2 if it is missing. GitHub's source archives are for developers.

## Changes in this release

- The final setup step now offers **Start without background startup**. The proxy runs while ICA proxy is open and stops when the app closes or quits. It does not start automatically after sign-in. The choice is remembered; after reopening, select **Start proxy** to run again.
- Foreground setup retains the provider and trusted-HTTPS checks. It avoids new OS startup enrollment and removes enrollment from an earlier setup attempt before switching. Existing installations keep their background behavior.
- Settings explains the selected mode and offers **Enable background startup** later. Enabling it after setup uses the current configuration, including HTTP-only settings chosen afterward.
- The **Remember Keychain access on this Mac** panel now uses a blue background, matching border, and readable text colors in dark mode, consistent with the app's other information panels.
- Includes the guided setup, optional **Skip setup**, background-startup recovery, and macOS bundle-signature verification from v0.2.2.

## Upgrade and configure

Quit ICA proxy settings, replace the installed app using the appropriate installer, and reopen the installed copy. Keep your saved provider keys, settings, and HTTPS identity; do not use **Reset data / prepare to uninstall** for this update. macOS may request renewed **Always Allow** approval for the worker after its executable changes.

New installations can choose either run mode in the wizard's final step. Both guided choices require one saved provider and trusted local HTTPS. Claude for Office uses `https://localhost:8788/claude` and the same Claude API key saved in ICA proxy. Default upstream endpoints remain `https://api.servicesessentials.ibm.com` for Claude and `https://api.servicesessentials.ibm.com/v1` for OpenAI. Each computer needs its own HTTPS setup.

Background mode keeps the worker running when settings closes and enables sign-in startup, subject to OS approval. Foreground mode stops when the app closes or quits; keep it open while using clients. See the [installation instructions](https://github.com/rickie-austin-114/llm_proxy/blob/v0.2.3/README.md#install-and-configure) for setup and approval recovery. The older Word guide shows the previous setup and tray behavior.

## Preview limitations

Mac apps use ad-hoc signing without Apple Developer ID signing or notarization. The Windows installer has no publisher signature. Operating-system or organization policies may block these development packages; signed production installers are pending.

Automated tests and package verification do not establish clean-account install/upgrade/uninstall, native credential and certificate prompts, native foreground close/quit/crash behavior, OS background registration/handoff, sign-in/reboot behavior, or a live Office/provider connection. Combined background RAM below 200 MB, ideally below 100 MB, remains an unmeasured release gate. See the [validation notes](https://github.com/rickie-austin-114/llm_proxy/blob/v0.2.3/VALIDATION.md) for completed checks and pending acceptance work.
